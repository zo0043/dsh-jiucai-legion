## 三、发现的问题与修复（本轮 10 项）

| # | 问题（数据流视角） | 修复 | 证据 |
|---|--------------------|------|------|
| 1 | **资金面「采而不食」**：两融/北向每运行真实拉取+缓存+标注，但 `marginBalance/northboundNet` 在引擎侧零引用——#16 的机构外生数据从未到达任何 Agent | Python `get_funds` 增 `marginAsOf/northAsOf`（两融 T+1 不得冒用北向日期）→ snapshot 透传 → `FundsInfo` 扩字段 → info-set 公共块新增「资金面」行（北向停披露如实报「未披露」） | pytest 断言 per-field asOf；vitest 断言渲染 |
| 2 | **情绪热度跨源量纲污染**：雪球=关注均值（可能上万）、东财=榜单条目数（恒 100），注入 Agent 时是裸数字——跨源切换日 Agent 世界里热度跳数百倍 | info-set 随值标注量纲语义（「榜单条目数」「关注均值」）+「跨源量纲不同，仅与同源前值比较」 | vitest 两源断言 |
