## 3. 端口定义（src/host/ports.ts）

```ts
export interface LlmMessage { role: 'system'|'user'|'assistant'; content: string }
export interface LlmPort {
  stream(req: { messages: LlmMessage[]; temperature?: number; maxTokens?: number }):
    AsyncIterable<string>;   // 增量文本片段
}
export interface SubprocessPort {
  spawn(cmd: string, args: string[]): { stdin: Writable; stdout: AsyncIterable<string>; stderr: AsyncIterable<string>; kill(): void };
}
export interface UiPort {            // Plan B 降级共用（#8 Plan B）
  renderMarkdown(md: string): Promise<void>;   // DSH: 斜杠命令输出；mock: stdout
}
export interface ClockPort { now(): Date; tz(): 'Asia/Shanghai' }  // #38 时区固定
export interface HostPorts { llm: LlmPort; proc: SubprocessPort; ui: UiPort; clock: ClockPort }
```

`mock-host.ts`：脚本化 LLM（按调用序返回预置 JSON 输出）、进程内数据子进程替身。所有引擎测试经 MockHost 运行，**零网络、零 LLM 调用**。

## 5. 引擎核设计

### 5.1 人设池生成（persona-pool.ts，#10/#11/#39/#48/#49）
- **确定性**：`createPool(seed: number, overrides)` → 同 seed 同池（测试可复现）。
- **三维分布**：资金规模 4 档 × 风格 7 类 × 情绪稳定性 3 档；总 30 = 散户 25 + 游资 5（`style ∈ {hotmoney, speculator, chasing}` 的资金档位强制 3/4）。
- **逆向占比下限**：`contrarian + indexer + (bear stance) ≥ 30%`（#40 拒绝阻尼后的结构对冲，属人设多样性而非价格侧干预）。
- **立场先验**：bull/bear/range 按风格条件分布（趋势派偏 bull、逆向派偏 bear），写进 systemPrompt。
- **偏差标签**：散户每人 1–2 个；游资 0 个但必带 `discipline.maxLossPct`（默认 5）。
- **systemPrompt 编译**（prompts.ts）：人设卡（风格/资金/立场/偏差/纪律）+ 输出 JSON 契约 + 「风格锚不可变」声明；编译一次，终身不重写（#15）。

### 5.2 情绪引擎（emotion.ts，#48）
```
emotion_{t+1} = clamp( baseline
  + Σ_events Σ_days decay(d) × dir(e) × strength(e) × 4      // 事件卡(#42)，线性衰减
  + clamp(unrealizedPnlPct, -5, 5) × 6 × (1/stability)        // 个人盈亏
  + clamp(|marketRet| - 0.01, 0, 0.05) × sign(marketRet) × 400 × (1/stability)  // 大盘波动
, 0, 100)
```
- 全部常量为可调配置（进设置页 #48）；上式为默认值。
- 逐日衰减：事件贡献按 `max(0, 1 - d/decayDays)` 线性衰减（#42 默认 2 天）。

### 5.3 信息集与提示词（info-set.ts，#12–#14/#50）
- **公共块（模板拼装，零 LLM）**：最近 5 日行情表、成交变化、涨跌家数/涨停梯队、情绪热度、新闻 TopN、**军团上轮倾向一句**（「军团兄弟上一交易日 63% 看多」——回流粒度=交易日级，K 轮互不可见，#50 澄清）。
- **风格专属块**：技术派→K线量能明细；消息党→新闻全文；游资→涨停梯队/连板高度明细。
- **个人块**：当前仓位、成本/现价/浮盈亏（#49）、当前情绪值、记忆摘要（含「近 10 次判断错了 7 次」统计行，#52）。
- **呈现顺序随机化**：块序按 round 种子打乱（#39）。
- **输出契约**：严格 JSON `{target_position_pct: 0–100, confidence: 1–5, reason: "≤30字"}`；解析失败→重试→仍失败计缺失。

### 5.4 编排器（orchestrator.ts，#54）
- 并发池默认 6 路（可配）；单 Agent 失败重试 2 次（指数退避 500ms）。
- 部分失败：缺失者按缺失聚合，日报标注「本轮仅 N/30 参战」；**< 24/30 整轮作废**（预测模式：该轮从分布剔除；K=5 全作废则预测失败）。
- 每轮全量轨迹（输入信息集哈希 + 每个 Agent 原始输出）落盘 → 回放源（§7）。

### 5.5 聚合（aggregate.ts，#43/#44/#51）
```
权重 w_i = capitalTier 权重 × (游资? hotMoneyAmp : 1)     // hotMoneyAmp 默认 3，滑杆可调
capWeight = [1, 2, 4, 8][tier-1]
净流 NF = Σ_i w_i × capWeight_i × (target_i − current_i)/100 × conf_i/5   // 置信度调幅(#51)
方向 dir = sign(中位数(NF_rounds))                        // #44 中位数符号
命中判定：|实际涨跌| < 0.1% → 平局，剔除分母(#44)
```

### 5.6 冲击映射（impact.ts，#21）
```
offsetPct = k_uncalibrated × (NF / Σ|w_i·capWeight_i|) × σ20d_annualized
k_uncalibrated 默认 0.8（拍定常量，面板明示「未校准」）；线性（凹函数随 #40 一并否决）
```

### 5.7 预测模式（predict.ts，#18/#36/#50）
1. 拉取 MarketSnapshot（行情不新鲜→硬失败，#24/#35）。
2. 第 1 日：K=5 轮 × 30 Agent（150 次 LLM）；每轮独立温度采样，K 轮之间互不可见。
3. 第 2–5 日：K=1 递推——用前一日预测收盘构造「预测态快照」（外生输入沿用锚定日、情绪/记忆延续），30 次/日。
4. 输出：逐日路径 + p10–p90 带 + 第 5 日终点分布 + 误差累积明示（band 逐日加宽）。
5. 分歧度 = 5 轮方向不一致度；过窄（5 轮同向且 NF 离散度 < 阈值）→ `dispersionNarrow=true` 日报告警（#39）。

### 5.8 沙盘模式（sandbox.ts，#37/#38/#40/#41）
- 逐日内生循环：`snapshot_{t+1} = impact(NF_t) + snapshot_t`；无价格侧阻尼（#40）。
- 外生变量第 0 日冻结，贡献 × `max(0, 1 - t/5)` 衰减；日报标注「沙盘 N 日后数据为内生推演」（#41）。
- K 默认 1（设置页可调，#38）；一次性连续跑完（#37）。
- 军团倾向回流：每日结束后计算军团看多比例，拼入次日氛围摘要（#50）。
- 事件卡注入后按衰减日历逐日生效（#42）。

### 5.9 what-if 事件卡（event-card.ts，#19/#42）
- `parseEvent(text)` → LLM 展开为 EventCard（板块/方向/强度/原文），面板可编辑后重跑。
- 定向注入：`sectors ∩ 风格兴趣集 ≠ ∅` 的 Agent 在信息集看到卡片（消息党/游资优先级最高）；强度→情绪偏移（§5.2）；持续 decayDays 线性衰减。
- 一键剧本：总编生成 3 个预设推荐（#33/#51 产品层）。

### 5.10 总编（editor.ts，#30）
- **Map**（纯计算）：30 条 reason 按当日方向分阵营（多/空/观望=|target−current|<5%），各阵营聚合：人数、平均目标仓位、情绪均值、3 条代表性发言（最长/最极端/最反差）。
- **Reduce**（1 次 LLM）：输入聚合摘要 + 分歧度统计 + 沙盘标注 → 输出《今日散户生态观察》Markdown（股吧体 #34；含「今天军团吵得特别凶」类分歧度话术）。

### 5.11 对账（reconcile.ts，#35/#44）
- 记录 `{anchorDate, horizon: '1d'|'5d', predictedDirection, predictedMedianPct, actualPct, settledAt}`。
- 结算：horizon 到期自动用日线补齐实际收盘（隔多日补跑容忍，#42 技术默认）。
- 命中率：平局剔除分母；滚动窗口 20 次统计 → 预测页顶部。

## 6. Python 数据子进程（python/djiucai_data/，#5/#22–#25/#32–#42/#45–#47）

**协议**：stdout 逐行 JSON（`{"id":1,"ok":true,"data":…,"asOf":"…","degraded":[…]}`），stdin 逐行请求（`{"id":1,"op":"getSnapshot","params":{…}}`）；崩溃→TS 侧重启并重试当前请求（#42）。

**Ops**：`ping` / `getCalendar` / `getDailyBars(index, days)` / `getSnapshot(index, date)`（聚合宽度+情绪+新闻+资金面，一次返回 MarketSnapshot 的 Python 侧字段）。

**数据源映射**（akshare，全部失败重试 2 次 + 版本告警 #25）：

| 数据 | 主源 | 备源/降级 |
|------|------|-----------|
| 日线 | `stock_zh_index_daily` (akshare) | baostock 交叉校验 OHLC（偏差>0.1% 告警，以 akshare 为准，#42） |
| 交易日历 | `tool_trade_date_hist_sina` | 本地缓存（#37） |
| 涨停池/炸板/连板 | `stock_zt_pool_em` 系 | 缓存降级+标注（#22） |
| 涨跌家数 | 指数成分/全市场行情聚合 | 缓存降级 |
| 情绪热度 | 雪球关注/讨论榜 | **东财人气榜互备**（#30 双源） |
| 新闻 | 新浪快讯 | 财联社电报互备（#23） |
| 两融 | `stock_margin_sse` 等（T+1 可得，取最近可得+asOf 标注 #47） | 缓存降级 |
| 北向 | 盘后披露接口（沪股通口径；沪深300→沪深合计 #47） | null + 标注 |

**缓存**：`data/cache/{op}/{date}.json`，全量保留无清理（#42）；降级读取时 `degraded` 数组标注来源与截至日。**时区**：全部日期按 Asia/Shanghai（#38）。**首跑回补**：日线 250 交易日；情绪/新闻零回补（#45）。**口径**：不做成分过滤，面板标注（#47）。
